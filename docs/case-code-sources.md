# 사건부호 의미와 저장 codec의 분리

검토일: 2026-09-23

`pipeline/compress.py`의 `CASE_CODE_MAP`은 사건부호를 짧은 ASCII 키로 바꾸는
저장 codec이다. 로마자 값은 법적 분류 코드가 아니며, 사건의 심급·종류·유효성을
판정하는 근거로 사용하지 않는다. 주석의 자연어 설명이 codec의 동작과 무관한데도
도메인 명세처럼 재사용되는 문제를 막기 위해 의미 설명을 매핑에서 제거했다.

공식 사건구분은 법원 사건구분 안내를 기준으로 확인한다.

- 행정: <https://daejeon.scourt.go.kr/common/util/sagubun_08.jsp>
- 가사: <https://daejeon.scourt.go.kr/common/util/sagubun_07.jsp>
- 법원 사건구분 전체: 위 페이지의 `전체` 및 사건유형별 탭

이번 검토에서 확인한 대표 정정은 다음과 같다.

| 사건부호 | 공식 안내 | 과거 잘못된 주석 |
| --- | --- | --- |
| `누` | 행정항소사건 | 행정 상고 |
| `두` | 행정상고사건 | 행정 재항고 |
| `드단` | 가사1심단독사건 | 행정 항소 단독 |

공식 표의 현재 의미를 역사적 사건에 무조건 소급하지 않는다. 구 사건부호나 사용
시기가 달라진 부호는 원천 레코드를 보존하고, 별도의 시기·출처가 있는 분류 자료가
마련되기 전에는 UI에서 의미를 단정하지 않는다. codec 키를 변경해야 하는 경우에는
기존 `db.json` 및 IndexedDB snapshot과의 명시적 마이그레이션이 필요하다.

## 사건번호 지원 범위 정책

- 2자리 연도는 실행 시점의 현재 연도를 넘지 않는 가장 가까운 과거 연도로 확장한다.
- 법원 1945년, 헌법재판소 1988년 하한은 현재 제품과 공개 DB의 조회 지원 정책이다.
  그 이전 표기를 빨강으로 표시하더라도 법적으로 사건이 존재할 수 없다는 판정은 아니다.
- 미래 연도와 일련번호 0은 구조 경고로 처리한다. 등록되지 않은 사건부호는 추출하지
  않으며, 미지원 표기를 허위 사건으로 분류하지 않는다.
- 정확히 4글자인 표기(`2자리 연도 + 1글자 사건부호 + 1자리 일련번호`)는 일반
  문장과 충돌하기 쉬우므로 활성 DB snapshot에 실제 존재하는 압축 키만 탐지한다.
  이 목록은 DB와 함께 파생·전환하며, 없거나 손상되면 4글자 탐지만 fail-closed한다.
  5글자 이상 사건번호와 4자리 연도 공식 인용(`2026헌가1` 등)은 이 제한을 받지 않는다.
- 같은 사건번호 키에 복수 레코드가 있으면 모두 보존하고 후보 목록으로 표시한다.
