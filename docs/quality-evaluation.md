# 품질 평가와 실제 사이트 호환성 점검

이 문서는 자동 테스트가 입증하는 범위와 실제 서비스 점검을 분리한다. 테스트 통과는
공개 자료 전체의 법률적 정확성이나 모든 AI 서비스의 항상 정상 동작을 보장하지 않는다.

## 자동 검증 계층

1. Jest: 사건번호 경계, 상태 의미, 동기화 정책, snapshot 원자성
2. Python unittest: 수집 실패, backlog, 게시 차단, 전수 스키마 검증
3. Playwright: 패키지된 확장의 migration, 동기화, 렌더링, 외부 통신 차단
4. `npm run eval:extraction`: 경계용 합성 자료와 번들 DB에서 파생한 4글자
   canonical 목록의 추출 정밀도·재현율

평가 자료는 `evaluation/extraction-fixtures.json`에 있다. 일반 경계 표본은 실제 사건의
존재를 주장하지 않지만, 정확히 4자인 표본은 현재 번들 DB 수록 여부를 기대값으로 삼는다.
보고할 때 표본 수, fixture schema, 확장 버전과 함께 precision/recall을 기록한다.
DB 수록률, 잘못된 초록 표시율, 검증 미완료율은 추출 지표와 섞지 않는다.

## 판정 분모

- 추출 precision: 추출 결과 중 정답 사건번호인 수 / 전체 추출 수
- 추출 recall: 정답 사건번호 중 추출된 수 / 전체 정답 수
- 잘못된 확인 표시율: 원문 식별자가 일치하지 않는 초록 표시 / 전체 초록 표시
- DB 미확인율: 정상 추출 중 현재 snapshot에서 찾지 못한 수 / 정상 추출 수
- 처리 미완료율: 시스템 오류·시간 초과로 회색 상태가 된 수 / 조회 시도 수

판결 내용 일치는 현재 제품이 판정하지 않으므로 별도 사람이 검토하는 정답 항목으로
두며 초록 표시의 정확도에 포함하지 않는다.

## 실제 사이트 smoke 기록

실제 서비스 점검은 계정 권한과 서비스 이용조건을 지키며 읽기 전용 공유 대화 또는
승인된 테스트 계정으로 수행한다. 개인 대화·프롬프트를 수집하지 않는다.

| 날짜 | 브라우저/확장/DB | 플랫폼 | DOM·스트리밍·재렌더 | 결과/알려진 한계 |
| --- | --- | --- | --- | --- |
| 미실행 | 기록 필요 | ChatGPT | 공유 대화 우선 | 릴리스 담당자 확인 필요 |
| 미실행 | 기록 필요 | Gemini | 스트리밍·강조 태그 | 릴리스 담당자 확인 필요 |
| 미실행 | 기록 필요 | Claude | 응답 컨테이너 | 릴리스 담당자 확인 필요 |
| 미실행 | 기록 필요 | Copilot | 재렌더·단축키 | 릴리스 담당자 확인 필요 |
| 미실행 | 기록 필요 | Perplexity | 복수 인용 | 릴리스 담당자 확인 필요 |
| 미실행 | 기록 필요 | Grok | 스트리밍 | 릴리스 담당자 확인 필요 |

실행하지 않은 라이브 점검은 통과로 표시하지 않는다. 고정 E2E는 외부 네트워크가
차단된 상태에서 재현되어야 하며, 라이브 smoke 결과는 릴리스 체크리스트에 첨부한다.
