# 품질 평가와 실제 사이트 호환성 점검

자동 테스트와 실제 서비스 점검 결과를 구분한다. 테스트 통과가 공개 자료 전체의
법률적 정확성이나 모든 AI 서비스의 항상 정상 동작을 보장하지는 않는다.
초록 배지는 현재 DB에 사건번호가 있음을 뜻하며 인용 내용 일치 판정은 아니다.

## 자동 검증

- Jest: 사건번호 경계, 판정 상태, 설정 유지, snapshot 원자성, 배지·뷰어·팝업 동작.
- Python unittest: 수집 실패와 backlog, 게시 차단, 전수 스키마와 원문 근거 검증.
- Playwright: 패키지 확장의 설치·migration·동기화·렌더링. 격리 브라우저의 합성 DOM과 모의 네트워크를 사용한다.
- `npm run eval:extraction`: `evaluation/extraction-fixtures.json`의 추출 지표.
- `npm run eval:standard`: [표준 테스터](standard-tester.md)의 사건번호 10개와 선택한 DB의 판정을 비교한다.

| --- | --- | --- |

자동 검증은 원문 열기·닫기·재열기·응답 역전·HTTP 오류 후 복구, 키보드와 포커스 복귀,
필터 변경 시 draft·focus·URL·페이지 realm 보존, popup 설정·대비·스크롤,
상단 가장자리 및 좁은 화면 접근을 검사한다. 6개 서비스·9개 허용 host의 합성 검사는
실제 서비스의 현재 DOM이나 계정 환경을 검증한 결과와 구분한다.

## 지표 해석

- 추출 precision: 추출 결과 중 정답 사건번호 수 / 전체 추출 수.
- 추출 recall: 추출한 정답 사건번호 수 / 전체 정답 사건번호 수.
- 잘못된 확인 표시율: 원문 식별자가 일치하지 않는 초록 표시 / 전체 초록 표시.
- DB 미확인율: 정상 추출 중 snapshot에서 찾지 못한 수 / 정상 추출 수.
- 처리 미완료율: 시스템 오류·시간 초과로 회색 상태가 된 수 / 조회 시도 수.

일반 경계 표본은 사건의 실재를 주장하지 않는다. 정확히 4자인 추출 표본은 번들 DB의
canonical 목록을 기대값으로 사용한다. DB 수록률과 판정 상태를 추출 지표에 섞지 않는다.
평가를 갱신할 때 fixture schema·표본 수·확장 버전·DB 버전과 해시를 함께 기록한다.

## 실제 사이트 수동 smoke

2026-11-02 사용자가 직접 입력·조작하고 결과를 보고했다. 자동 서비스 조작은 수행하지 않는다.
[수동 프로토콜](standard-tester.md)에 따라 판정 색, 원문 열기·전환·닫기, 필터,
키보드를 확인했다. 표는 사이트별 실제 수행 여부의 기준 기록이다.

수동 smoke는 사용자 보고에 근거하며 미관찰 항목을 통과로 간주하지 않는다.
최종 제출 전에는 실제 ZIP과 검사 대상 소스가 같은지 확인하고,
출시 절차는 [릴리스 체크리스트](release-0.9.0.md)를 따른다.
