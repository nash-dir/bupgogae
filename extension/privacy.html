한국어

법고개 개인정보처리방침

법고개는 지원되는 AI 채팅 사이트의 응답에 표시된 사건번호를 확인합니다. 화면의 텍스트를 읽어 사건번호 패턴을 찾고 현재 브라우저의 공개 판례 DB와 로컬에서 대조합니다. 프롬프트나 답변 텍스트를 법고개 서버 또는 외부 분석 서비스로 전송하거나 영구 저장하지 않습니다.

소스코드: github.com/nash-dir/bupgogae

1. 기기에 저장하는 항목

  • IndexedDB의 공개 판례 DB snapshot과 버전·무결성 메타데이터
  • chrome.storage.local의 ETag, 동기화·drift 이력, 검증된 원격 selector 설정과 환경설정
  • 사이트별 활성/비활성 설정에 필요한 지원 사이트 호스트명

2. 외부 통신

호스트·시점목적저장
api.bup.live
설치·시작·주기 동기화 및 지원 사이트 진입		공개 DB(db.json.gz), 무결성·버전 manifest(manifest.json), 검증된 selector 설정(adapters.json) 확인 또는 다운로드DB와 메타데이터는 로컬에, selector 설정은 chrome.storage.local에 저장
www.law.go.kr
사용자가 원문 열기 요청		공개 일련번호를 이용한 선택한 법령·판례 HTML 조회현재 탭에 표시하며 가져온 HTML은 확장프로그램 영구 저장소에 기록하지 않음
portal.scourt.go.kr 등
사용자가 외부 링크 선택		선택한 공공 확인 페이지로 브라우저 이동대상 페이지 내용을 확장프로그램이 영구 저장하지 않음

통신 대상 호스트에는 각 호스트의 정책에 따라 IP 주소 같은 일반적인 연결 정보가 보일 수 있습니다. 업데이트·설정 요청에는 프롬프트, 답변 텍스트, 사용 통계, 광고 식별자 또는 분석 payload를 추가하지 않습니다. 패키지 내부의 data/adapters.json, 메타데이터, 번들 DB fallback을 읽는 fetch는 확장프로그램 로컬 URL이며 외부 요청이 아닙니다.

3. 권한

  • alarms: 6시간 주기 DB 동기화
  • storage / unlimitedStorage: 환경설정·동기화 상태와 공개 DB snapshot의 로컬 저장
  • 지원 AI 사이트 접근: 표시된 답변 텍스트의 로컬 판별과 배지 표시
  • api.bup.live 접근: DB·manifest·selector 설정 다운로드
  • www.law.go.kr 접근: 사용자가 요청한 원문 조회

manifest는 tabs 권한을 요청하지 않습니다.

4. 배지 의미와 한계

  • 초록: 현재 브라우저의 활성 공개 DB에서 해당 사건번호를 찾음
  • 주황: 현재 로컬 DB에서 해당 사건번호를 찾지 못함
  • 빨강: 사건번호 형식 검사를 통과하지 못함

배지는 판례의 진위·법적 유효성·안전성, 공공 출처의 완전성 또는 AI 답변 전체의 정확성을 보장하지 않습니다. 주황은 새 판례이거나 공개되지 않았거나 현재 DB에 아직 포함되지 않은 경우에도 표시될 수 있습니다.

English

Privacy Policy

Bupgogae reads displayed response text on supported AI chat sites to find Korean case-number patterns and compares them with the active public database locally in the browser. It does not send prompt or response text to the Bupgogae server or another analysis service, and does not persist that text.

Stored on the device

The Extension stores public database snapshots and metadata in IndexedDB, and stores the ETag, sync/drift history, validated remote selector configuration, preferences, and any supported host names used for per-site settings in chrome.storage.local.

Supporting network communications

  • api.bup.live: automatic database, integrity/version manifest, and validated selector-configuration checks or downloads at install/startup, on the sync schedule, and when a supported site is opened. These files and metadata are stored locally.
  • www.law.go.kr: a user-requested original-document fetch using the selected public serial identifier. Retrieved HTML is displayed in the current tab and is not written to persistent extension storage.
  • portal.scourt.go.kr or another displayed public source: browser navigation only after the user selects the link.

Contacted hosts can observe ordinary connection information under their own policies. Bupgogae does not add prompt text, response text, telemetry, advertising identifiers, or analytics payloads to update/configuration requests. The manifest does not request the tabs permission.

Badge meaning

  • Green: the case number was found in the active public database.
  • Orange: the case number was not found in the current local database.
  • Red: the case-number form failed structural checks.

The badges do not guarantee authenticity, legal validity, safety, source completeness, or the accuracy of the surrounding AI answer.
