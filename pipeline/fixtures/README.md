# 병합 사건 회귀 표본

`law-merged-420836.xml.gz`는 2026-10-17 KST에 수집한 법제처 공개 API의
2020년 6월 응답에서 ID 420836의 `prec` 요소를 변경 없이 추출했다.
테스트 envelope만 단일 원문 1건으로 만들었고 gzip mtime은 0이다.

지방세연구원 원문에도 서울행정법원 2020-06-11 선고의 1심 표제에
`2019구합77422, 77439(병합), 77484(병합), 77514(병합), 77521(병합)`이
명시되어 있다.

<https://www.olta.re.kr/explainInfo/detailView/decisionDtlView.do?num=60090520&relationshipNum=20001598&srchWrd=>

`merged-420836-export.json`은 위 원문을 현행 parser → 임시 master DB → export로
생성한 5개 키의 snapshot 조각이다. Python 회귀가 실제 export와 동일함을
검사하고, 브라우저 E2E가 같은 조각을 사용해 전수 설치·배치 조회를 확인한다.
5개의 별도 판결이나 원문을 뜻하지 않으며 운영 DB를 보충하는 파일도 아니다.

국세 출처 33건 및 특허 사건은 이번 추가 보완·복구에서 제외했다.
기존 `law-201811/` 표본과 정기 수집 정책은 유지한다.

## 본소·반소 표제

`law-main-counterclaim-pairs.json`은 같은 날짜에 확보한 법제처 공식 상세 XML
9건의 사건번호·법원·선고일·사건명 필드다. 각 행에 원문 URL과 보존한 상세 XML의
SHA-256을 함께 기록했다. 두 번호 모두 전체 표기로 명시돼 있으며 추정하거나
일부 번호를 제거한 값이 아니다. 회귀 시험은 원문을 저장한 뒤 두 키가 모두
export되는지와 대표 번호만 주는 후속 갱신이 거부되는지를 확인한다.
