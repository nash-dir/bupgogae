상태: 심사 제출 준비. 심사 제출·승인·스토어 공개 완료를 의미하지 않습니다.

[짧은 소개]
AI 답변의 한국 사건번호를 브라우저의 공개 판례 DB와 대조하고, 배지와 원문 확인 링크를 제공합니다.

[상세 소개]
법고개(Bupgogae)는 AI 답변에 나온 한국 사건번호를 확인하는 도구입니다.
ChatGPT, Claude, Gemini, Copilot, Perplexity, Grok의 답변에서 사건번호를 찾아 현재 브라우저에 저장된 공개 판례 DB와 대조합니다.

초록은 현재 DB에서 찾은 사건번호, 주황은 로컬 DB에서 찾지 못한 사건번호입니다. 빨강은 형식·지원 범위 경고, 회색은 시간 초과나 오류로 조회를 완료하지 못한 상태를 뜻합니다.

배지를 눌러 사건명·선고일·법원과 원문 확인 링크를 볼 수 있습니다. 주황이나 빨강 표시만으로 판례가 존재하지 않는다고 단정하지 않습니다. 초록 표시 역시 인용 내용이나 AI 답변 전체의 정확성을 보장하지 않습니다. 중요한 인용은 반드시 원문을 확인하세요.

답변 텍스트의 분석과 DB 대조는 브라우저 로컬에서 수행하며, 프롬프트·답변 텍스트를 외부 분석 서버로 전송하지 않습니다. 공개 DB·manifest·검증된 화면 선택자 설정은 api.bup.live에서 확인하거나 갱신합니다. 사용자가 원문 조회를 요청하면 선택한 공개 일련번호로 법제처에 요청합니다.

개인정보처리방침: https://api.bup.live/bupgogae/privacy.html

[0.9.0 변경사항 — 짧은 버전]
• 원문 대조로 검증한 누락 판례를 DB에 반영하고 사건번호 정규화를 보완했습니다.
• 6개 주요 챗봇의 응답 화면 대응과 배지·툴팁 표시를 보강했습니다.
• DB 미확인과 조회 실패를 구분하고, 배지의 의미와 데이터 출처 안내를 정비했습니다.
• DB를 전수 검증한 뒤 전환하고, 실패 시 마지막 정상본을 유지하도록 동기화 안정성을 강화했습니다.
• 기존 클라이언트의 DB 경로를 유지하면서 0.9.0용 계약 경로를 추가했습니다.

[0.9.0 변경사항 — 상세 버전]
판례 DB 누락 복구와 사건번호 표시·동기화 안정성을 중심으로 개선했습니다.

1. 데이터 복구와 정규화
2016도10912 등 원문 대조로 검증한 누락 판례를 반영했습니다. 수집 응답과 사건번호 정규화를 보완하고, 병합 사건번호를 일부 누락하지 않도록 회귀 검사를 추가했습니다. 법원 약칭은 근거 없이 추정하지 않습니다.

2. 챗봇 화면 대응
ChatGPT, Claude, Gemini, Copilot, Perplexity, Grok의 실제 응답 화면에서 배지와 툴팁을 점검했습니다. 사용자 메시지·입력창 제외와 응답 재렌더링 시 표시를 확인했으며, 개인용·업무용 Copilot 도메인 대응도 보완했습니다.

3. 배지와 출처 안내
현재 로컬 DB에서 찾지 못한 주황 상태와 조회를 완료하지 못한 회색 상태를 구분합니다. 배지로 판례의 부존재나 인용의 진위를 확정하지 않도록 안내를 정비하고, 확장 팝업에 법제처 공동활용 출처를 명시했습니다.

4. 동기화 무결성
버전·건수·해시와 전체 레코드를 검증한 뒤 새 DB로 전환합니다. 중복 동기화를 합치고, 불완전한 데이터나 이전 버전으로 교체되지 않도록 보호하며, 실패 시 마지막 정상 DB를 유지합니다.

5. 구버전 호환
기존 DB·manifest 경로를 유지하면서 0.9.0 계약 경로를 추가했습니다. 운영 서버에서 구버전 0.8.2 기준 확장과 최종 0.9.0 ZIP의 실제 동기화를 확인했습니다.

※ 이번 업데이트에 문서 업로드·문서 전체 검증 기능은 포함되지 않습니다.
